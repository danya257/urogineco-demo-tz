# Демо сайта Гвоздева М.Ю. — версия по ТЗ от 09.07.2026

Статический слепок Django-сайта: страницы операций (7 заболеваний), памятки пациенткам
с версией для печати, «Обо мне», «Вопрос-ответ», подменю «Операции», форма записи
с вложением и QR-кодом Telegram.

Открыть: https://danya257.github.io/urogineco-demo-tz/

Формы в демо не отправляются. Рабочий код — ветка `prod-beget` в репозитории
[danya257/urogineco](https://github.com/danya257/urogineco/tree/prod-beget).

## Видео в демо

Видео врача ещё не снято, поэтому в баннере, на странице «Недержание мочи» и в карточке
мероприятия стоят демонстрационные ролики из бесплатного стока
([Pexels](https://www.pexels.com/license/), свободная лицензия) — их заменит своё видео.
